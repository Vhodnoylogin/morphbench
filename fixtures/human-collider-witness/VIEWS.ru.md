# Где открыть пробники в Morphbench

English: [VIEWS.md](VIEWS.md).

Установленный мод называется `test_Morphbench Human Collider Witness`.
Оба игровых NPC используют `meshes/test_morphbench_human/body/femalebody_1.nif`
при весе100. Скелеты различаются:

| Вариант | NPC base local ID | Скелет и HKX |
| --- | --- | --- |
| CONTROL FIT ×1 | 000806 | `meshes/test_morphbench_human/control/skeleton_female.nif` и одноимённый `.hkx` |
| MARKER LEFT ×3 | 000807 | `meshes/test_morphbench_human/marker/skeleton_female.nif` и одноимённый `.hkx` |

В обычном каталоге Morphbench включить **меши без морфов**: у этого нейтрального
пробника нет TRI, поэтому обычный фильтр его скрывает. Но выбора одного тела
недостаточно: его скелеты лежат отдельно, и автоматическое соседнее
`skeleton.nif` не назначит ни контроль, ни маркер. Положение капсул должно
считаться с соответствующим HKX, а не только с узлами NIF.

`view.py` создаёт два полноценных интерактивных вида **самого Morphbench** и
страницу сравнения. Он проверяет все7файлов установленного мода по сохранённому
manifest, явно открывает нужные skeleton/HKX, не подгоняет и не изменяет геометрию.
Капсулы уже включены; доступны поворот, ракурсы, фокус по костям и переключение
слоёв. Страница работает после закрытия основного сервера Morphbench.
Это снимок выбранных файлов, а не доступ ко всей виртуальной Data через MO2.

Запустить Python из установленной поставки Morphbench (либо совместимую среду)
и передать реальные пути:

```text
python fixtures/human-collider-witness/view.py --mod <installed-fixture-mod> --bench <Morphbench-folder> --out <new-external-viewer-folder>
```

Открыть созданный `index.html`: слева CONTROL, справа MARKER. Для большого
полотна открыть `control.html` и `marker.html` отдельно. На фронтальном виде
левое бедро персонажа находится справа для наблюдателя. В маркере его оболочка
заметно шире; все остальные капсулы совпадают с контролем. `viewer-manifest.json`
связывает виды с точными установленными файлами; `colliders.json` хранит их числа.

Для сравнения с игрой показать того же маркера и тот же контроль с `trd`,
поставить сходный ракурс, открыть соответствующий вид инструмента и сопоставить
сторону, привязку к бедру, ориентацию и увеличенную оболочку. Разницу поз из-за
игровой анимации записать отдельно. Один игровой кадр и подтверждение контакта
не заменяют это сравнение и не измеряют точный радиус живой капсулы.

Полный исходный наряд и успешность обездвиживания не следуют из успешного
визуального маркера. Новые файлы просмотра не меняют старые неизменяемые наряды
или выпуск Morphbench; в релиз они не включаются.

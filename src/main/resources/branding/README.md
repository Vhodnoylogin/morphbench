# Morphbench cover artwork

`cover-v1.png` is the maintained conceptual cover, generated with OpenAI image_gen
for the owner's Nexus publication on 10 October 2026. The author/publisher is
Vhodnoylogin; `cover-prompt.txt` records the prompt. This artwork is distributed
under this repository's GPL-3.0 licence. It contains no bundled Skyrim model.

Unlike the deterministic launcher icon, this chosen illustration is an
authoritative source resource. It is not recreated by the packaging process and
does not ship in Application or Runtime. Historical screenshots and fixture
renders are external publication/test evidence, not current source assets.

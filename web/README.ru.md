# `web\` — страница смотрелки

English version of this file — [README.md](README.md).

Страница лежит настоящими файлами — `page.html`, `style.css`, `js\*.js`, — а не строками
внутри Python. `presenters\assets.py` либо отдаёт их по одному (тогда перезагрузка показывает
правку), либо сворачивает в один самодостаточный файл, открывающийся по `file://`.

| Файл | Что в нём |
|---|---|
| `page.html`, `style.css` | разметка и вид |
| `js/core.js` | числа и подручное для всех остальных, включая `rnd()` и палитру |
| `js/shapes.js`, `js/view.js`, `js/render.js` | геометрия в браузере, состояние камеры, отрисовка |
| `js/bench.js` | фасад, повторённый метод в метод |
| `js/panel.js`, `js/app.js`, `js/boot.js` | панель, единственная дверь `App.invoke` и запуск |

Порядок загрузки объявлен один раз, в `PageAssets.SCRIPTS` (`..\presenters\assets.py`),
и больше нигде. Это **обычные скрипты, а не ES-модули**: объявления верхнего уровня одного
скрипта видны следующему, и потому один и тот же список работает и связанным, и свёрнутым.
Модуль не дал бы ничего, а свёрнутый вид сломал бы начисто — по `file://` браузер отказывается
делать `import`.

## Может зависеть от

**Полезной нагрузки, которую пакует `presenters/web.py`, и браузера.** Ни библиотеки,
ни шрифта, ни единого обращения, уходящего с машины: страница обязана работать из папки
с выдернутой сетью, а смотрелка, докладывающая куда-то о чужом моде, никому не нужна.

## Кто не вправе её импортировать

Из Python эту папку не импортирует никто. `assets.py` читает файлы по перечисленным именам,
и он единственный, кто знает об их существовании.

## Правило, которое решает, что здесь лежит

**Всякое действие страницы — одноимённый вызов фасада.** `js/bench.js` повторяет `MorphBench`,
а `App.invoke(method, ...args)` в `js/app.js` — единственная дверь, через которую проходит
каждая кнопка. Управление, делающее то, до чего не дотянуться из командной строки, ломает
свойство, ради которого всё устроено, — потому панель и печатает внизу равнозначную строку
`mb.py render`.

Одно следствие, которое стоит знать до правки `js/core.js`: `rnd()`, `Palette.hsvToRgb`
и `vertexNormals` — намеренные зеркала питоновских `round`, `colorsys.hsv_to_rgb`
и `model.vertex_normals`, один в один. Страница и ядро обязаны печатать одни и те же числа,
иначе та самая строка командной строки дала бы другой кадр. Меняешь одну сторону — меняй обе.
